# HSK TPS Booster

Makes HSK run faster.

+ A new interactive map mode
Everything can be switched on and off in the mod settings.

Performance capture: Ctrl+F9. When it is saved, a window with charts opens in game (Ctrl+F11 opens it any time):
frame and tick charts, cost per mod, and the method and def trees with search. Older captures can be picked from a list.

The interactive map is off by default. With Multiplayer enabled, only the map and
its zoom threshold remain adjustable; the other settings use their original defaults. In Multiplayer the map starts off
even if an older config had it on, until the player switches it there.

Requires RimWorld 1.6, Hardcore SK, Harmony, Performance Optimizer and Missile Girl.

# HSK TPS Booster

Ускоряет работу HSK.

+ Новый интерактивный режим карты
Всё включается и выключается в настройках мода.

Хочу посмотреть какой мод лагает
Ставите 3тью скорость и жмите ctrl+f9. Полученный архив присылаете в тему или смотрите сами.

Запись производительности: Ctrl+F9. Когда она сохранена, в игре открывается окно с графиками (Ctrl+F11 открывает его в любой момент):
время кадров и тиков, нагрузка по модам, деревья методов и дефов с поиском. Старые записи выбираются из списка.

Интерактивная карта по умолчанию выключена. При активном Multiplayer доступны только
карта и порог её включения; остальные настройки зафиксированы на исходных значениях по умолчанию. В Multiplayer карта
выключена, даже если старый конфиг её включал, пока игрок сам не включит её там.

Требует RimWorld 1.6, Hardcore SK, Harmony, Performance Optimizer и Missile Girl.
