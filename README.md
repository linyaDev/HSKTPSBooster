# HSK TPS Booster

Makes HSK run faster.

- Higher TPS, especially in big colonies
- Several bug fixes
- A new interactive map mode

Everything can be switched on and off in the mod settings.

The interactive map is off by default. With Multiplayer enabled, only the map and
its zoom threshold remain adjustable; the other settings are forced off before
startup fixes run, including when an older config enables them.

Requires RimWorld 1.6, Hardcore SK, Harmony, Performance Optimizer and Missile Girl.

# HSK TPS Booster

Ускоряет работу HSK.

- Выше TPS, особенно в больших колониях
- Несколько исправлений ошибок
- Новый интерактивный режим карты

Всё включается и выключается в настройках мода.

Интерактивная карта по умолчанию выключена. При активном Multiplayer доступны только
карта и порог её включения; остальные настройки принудительно выключены ещё до
применения стартовых фиксов, в том числе при загрузке старого конфига.

Требует RimWorld 1.6, Hardcore SK, Harmony, Performance Optimizer и Missile Girl.
